# Vineet Kumar — React Portfolio

A responsive one-page portfolio built with React + Vite.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the project folder in VS Code.
4. Open the terminal in this folder and run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
npm run preview
```

The production website is generated in the `dist` folder.
